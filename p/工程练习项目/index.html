建筑模型

Revit BIM模型

点击跳转 Revit制作的模型

以一栋地下一层、地上二至三层的独栋别墅为对象，完整演练从创建项目样板、绘制标高轴网，到搭建内外墙体、插入门窗、生成楼板、设计屋顶与楼梯扶手，再到布置柱梁结构构件和场地环境的整套建模流程。借助 Revit 的参数化设计特性，所有平面、立面、剖面及门窗明细表均与三维模型实时联动，直观展示建筑效果。

SketchUp 3D模型

点击跳转 SketchUp制作的模型

先依据其平面与立面图纸建立轴网，按照底层架空柱廊、二层起居空间、三层屋顶花园的竖向布局逐层拉伸体块，再细致刻画横向长窗、弧形墙体、螺旋楼梯及坡道等关键构件，最终呈现出一个既简洁纯粹又内部精巧镂空的现代建筑几何体。使用 SketchUp 的线面推拉、组件编组、路径跟随等技巧。

3dsMAX 3D模型

点击跳转 3dsMax制作的模型

导入CAD图纸，依据室内平面图搭建空间框架，通过墙体挤出与天花板吊顶造型确定整体布局，再依次导入云朵沙发、椭圆茶几、原木边柜等主体家具，利用涡轮平滑修改器处理软包与圆角构件，使所有造型保持风格统一。使用 V-Ray渲染器调配，同时确保色彩统一，在 Photoshop 里转为智能对象然后调整锐化、滤镜，AO图使用正片叠底，通道图放最下层方便选区。

Github 小工具开发

点击跳转 github横道图生成器

专为工程项目进度规划而设计。通过简洁直观的图形界面，用户可以快速维护项目任务清单，系统将自动根据起止日期计算工期，并实时渲染带有时间轴的横道图预览。无论是个人施工项目作业、研发计划，还是其他需要按时间线推进的工程，均可使用本工具进行可视化管理。提供独立可执行exe程序，无需安装 Python 环境即可运行。
